기분날씨 앱 4개 비교 평가

하루 기분을 날씨로 남기는 앱을 같은 요청으로 4번 만들었어요. 어느 쪽이 더 좋은지 솔직하게 평가해 주세요. 정답은 없고, 느낀 그대로가 제일 도움이 돼요.

평가는 이 휴대폰에만 저장되고 어디로도 자동 전송되지 않아요. 다 하면 맨 아래 결과 복사를 눌러 카톡으로 보내 주세요. 앱 하나에 3~5분이면 충분해요.

하는 법

  1. 아래 순서대로 앱 열기를 누르면 새 탭에서 앱이 열려요.
  2. 앱마다 이렇게 해 보세요.
    1. 처음 열고 10초 둘러보기(첫인상)
    2. 오늘 기분을 고르고 한 줄 메모 남기기
    3. 달력에서 오늘과 지난 날 보기(예시 데이터 기능이 있으면 눌러 보기)
    4. 주간 '기분 일기예보' 카드 보고 이미지로 저장해 보기
    5. 새로고침해서 기록이 남았는지 보기
    6. 1~2분 자유롭게 눌러 보기
  3. 이 탭으로 돌아와 점수를 눌러 주세요. 1 = 쓰기 어렵거나 깨짐, 3 = 무난한 보통 앱, 5 = 앱스토어 상위 앱 수준.
추천 순서:
사람마다 순서를 다르게 섞었어요. 보는 순서가 점수에 주는 영향을 줄이려는 거예요.

전체 순위

점수를 다 누르면 결과를 복사해 카톡으로 보내 주세요.
